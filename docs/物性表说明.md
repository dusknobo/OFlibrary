# 水/LiBr物性表

`data/librWaterTable.dat`是八库共享的运行时物性数据。数据来源、网格与SHA-256见[data/metadata.json](../data/metadata.json)。

## 格式

第一项为`LIBR_WATER_THERMO_V2`；随后依次为`nT nX Tmin dT Xmin dX`，再按温度外层、浓度内层排列每个节点的七个数值：

| 列 | 含义与单位 |
|---|---|
| 1 | rho，kg/m³ |
| 2 | 与同一焓模型一致的cp，J/(kg·K) |
| 3 | ln(mu)，mu单位Pa·s |
| 4 | ln(pEq)，pEq为绝对Pa |
| 5 | 水的微分相变焓差，J/kg |
| 6 | 溶液比焓，J/kg |
| 7 | dh/dX，X为质量分数 |

当前表为76×131节点，T范围278.15—353.15 K、X范围0—0.65。表核验工具只需C++标准库；`./Allwmake`会生成build/bin/table_audit。

```bash
printf '313.15 0.64\n287.15 0\n' | build/bin/table_audit data/librWaterTable.dat
```

输出依次为rho、比内能e和pEq。运行CFD时，膜mixture的tableFile和cloud的solutionTable应指向该文件的实际路径；路径和算例浓度/温度由使用者配置。

## 定义与适用范围

表使用CoolProp保存的原始Patek-Klomfar关联式与共同水能量参考，源实现保留在[src/librThermo/PatekNative.C](../src/librThermo/PatekNative.C)。水的微分相变焓差采用`hv-(h-X*dh/dX)`。随浓度改变参考的INCOMP焓差不应直接用于吸收放热。

该规则网格是关联式计算范围，不代表结晶稳定包络。表未提供溶液表面张力、互扩散系数或结晶边界，使用算例需要独立选择并核验这些闭合。导热系数采用单独的ASHRAE 526-RP实现，浓溶液有独立的温度适用限制。

原离线生成器名称保存在metadata的original_generator字段；本仓库随附运行时表及原始关联式实现，不依赖Python/CoolProp进行求解期查表。
